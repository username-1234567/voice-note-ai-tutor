## 1. 独立评审结果（规则 26）

**总分 7.2 / 10**

> 原文摘要："有明确的设计意图：中性色加单点绿、去掉卡片堆叠、CTA 下沉到拇指区，比改造前更像一款成熟产品。但核心页面存在层级倒置和一个肉眼可见的对比度事故。"

### 采纳并已修复

| # | 评审意见 | 处理 |
|---|---|---|
| 1 | 录音页把最重要的信息做成了最弱的文字：「第 3 张讲解中」是全屏最小最浅的一行 | 移到环下 22dp，与「已标记 N 个」同一行，13sp titleSmall，不再飘在按钮上方 |
| 2 | 录音页中段有 ~200px 空洞，信息与控制区各自成团 | 环 + 信息作为一个整体在剩余空间居中，留白集中到控制区上方 |
| 3 | 径向刻度没有起点、没有方向，语义读不出来 | 12 点方向加一道起点刻线；环下加图例「最近 60 秒 · 每根条 1 秒，长度是那一秒的音量」 |
| 4 | 首页「2 个未讲解」用了正红，把正常状态读成异常 | 文案改为「2 个讲解失败」（`markerFailed` 本来就是 `AI_FAILED` 计数，旧文案不准确）；红色保留，因为确实需要处理 |
| 5 | 三页头部是三套语言，录音页箭头夹在两行文字中间 | 录音页改为「单行标题 + 独立副标题」，副标题左缘与标题左缘对齐（48dp），箭头只对标题一行居中 |
| 6 | 设置页一屏三个薄荷绿块，主次全糊 | 「检查更新」由实心降为描边，一屏只留「忽略电池优化」一个实心 |
| 7 | 停止键比暂停还轻，破坏性最强的操作反而最弱 | 淡红底（error 8%）+ 红描边，仍不抢主 CTA |

### 未采纳（附理由）

| 评审意见 | 不采纳的理由 |
|---|---|
| 深色主按钮白字压薄荷绿 | **核对后不成立**：代码用 `onPrimary`（#00382D 深绿字），截图 mock 也是深绿字，评审看错了 |
| 首页时长应与课程名同行 | 左列是"时间事实"（几点开始 / 多长），右列是"内容事实"（哪门课 / 讲了几个点），这个分组是刻意的；改成一行会让右列挤到两行 |
| 暂停键像禁用 | 图标是 `onSecondaryContainer`（近黑），不是灰字；低饱和是刻意的次要层级 |

## 2. 自检清单结论

| 项 | 结果 |
|---|---|

| 未通过（已当场修复） | 4 |

### 当场修复的 4 项

| 编号 | 问题 | 修复 |
|---|---|---|
| `D4` | 分组头一行里 13sp / 11sp / 11sp 混排却用居中 | 三处文字改 `Modifier.alignByBaseline()`，细线仍居中 |
| `G4` | 空状态下仍显示搜索框与筛选（没有内容可作用） | 新增 `noRecordingsAtAll`，为空时隐藏搜索行；注意不能用 `sections.isEmpty()` 判断，搜索无结果时它也是空 |
| `G7` | 同一屏能数出 8/12/14/18 四种圆角 | 收敛为两档：10dp 控件 / 16dp 容器，`Shapes` 同步改 |
| `I6` | 页面切换 180–220ms，低于"整页 350–500ms"区间 | 进入 360ms、退出 240ms |

### 遗留 2 项

| 编号 | 说明 |
|---|---|
| `I7` 动效证据 | 无真机、无模拟器，只能提供静态渲染图；已用 Edge headless 验证画面，动效本身需装机确认 |
| `D5` 中文断行 | 长文案（设置页说明）目前靠系统断行，未做不可拆词保护；这些句子短，实测未见孤字，暂不处理 |

### 补充确认

- `I5` 三处动效齐了：主操作反馈（ripple + 实心 CTA）、状态切换来路（录音状态交叉淡入、音量条可中断推进）、首次出场（首页列表 260ms 淡入 + 14dp 上移，进程内只播一次）
- `I8` 「减少动态效果」：新增 `rememberReducedMotion()`，读 `ANIMATOR_DURATION_SCALE`；开启后页面切换与列表出场直接到位
- `E2` 彩色标签为浅底深字（状态 chip 用 `color@12%` 底 + 同色字），非深底白字
- `E3` 状态双通道：失败 = error 色 + 警示图标；待发送/发送中 = 色 + 圆点
- `J3` 深色模式：背景 #0E1312（非纯黑），主色提亮到 #6FD3B6，卡片改用色差而非阴影
