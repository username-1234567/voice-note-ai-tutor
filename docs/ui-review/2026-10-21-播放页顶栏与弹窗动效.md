# 播放页顶栏 · 弹窗窗体 · 按钮动效 改版记录

日期：2026-10-21
范围：`PlaybackScreen`（顶栏 / 播放控制 / 进度条 / 展开箭头 / 看图）、`AppAlertDialog`（全应用弹窗）、`RecordNavHost`（页面切换）
约束：功能与回调签名不变，只改视觉与交互反馈。

---

## 1. 为什么改

上一轮已经把配色、圆角、字号收敛过一遍，但播放页和三处交互仍是"能跑但没打磨"的状态：

| 现象 | 性质 |
|---|---|
| `enableEdgeToEdge()` 已开启，顶栏却没有 `statusBarsPadding()` | 布局缺陷：标题被状态栏压住，返回键落进手势区 |
| 顶栏与内容之间没有任何分界，滚动时标题像浮在列表上 | 层级缺陷 |
| 弹窗用 M3 默认 `AlertDialog`，**进出场没有任何动画** | 交互缺陷：点"删除"后弹窗凭空消失，用户无法确认刚才那一下生效了 |
| 弹窗按钮全是 `TextButton` 平铺，破坏性操作和"取消"长得一样 | 层级缺陷：违反按钮重要性金字塔 |
| 播放/暂停图标是瞬时切换的 `if/else` | 反馈缺陷：按钮按下去像没反应 |
| 倍速按钮显示 `1.0x`，无按压、无切换过渡、菜单项选中态无标记 | 细节缺陷 |
| 展开箭头 `rotationZ = if (expanded) 180f else 0f` | 瞬时翻转，看得见"跳" |
| 拖动进度条时播放头毫无变化 | 缺少"抓住东西"的触觉确认 |
| 页面后退时 `popEnter` 只有淡入、没有方向位移 | 方向感缺失：进入有横移、返回却没有 |

## 2. 顶栏

```
[←]  半导体物理 · 第三讲 载流子输运
     10月21日 14:05 · 37 分 12 秒
────────────────────────────────────  ← 滚动后才出现，1dp
```

- **补上 `statusBarsPadding()`**。这是本次唯一的"错"修复，其余是打磨。
- **滚动联动**：`firstVisibleItemIndex > 0 || offset > 2` 时，背景从 `background` 抬到 `surface`，同时淡入一条 `outlineVariant` 细线。两者都用 `animateColorAsState` / `animateFloatAsState`（220ms）。
  - 细线用**恒高 1dp 的 Box 改透明度**，不是 `HorizontalDivider` 动态显隐——后者会改变顶栏高度，导致 `Scaffold` 重新计算 content padding，整个列表上下跳一下。
- 返回键：图标 21dp、热区 48dp、按压缩到 0.90。
- 副标题：`labelMedium` + `tabularNumbers()`，与标题间隔 1dp。

深色下 `background #0E1312 → surface #141A18` 只差一档，是靠细线 `#3A423F` 完成分隔的，不是靠颜色差。

## 3. 弹窗

从 M3 `AlertDialog` 改成自绘 `Dialog`，因为**默认实现没有进出场动画**，而动画是这个组件最缺的东西。

结构：图标容器（可选）→ 标题 → 正文 → 自定义内容 → 按钮区。

| 项 | 值 | 理由 |
|---|---|---|
| 宽度 | `min(屏宽 - 56dp, 340dp)` | 平板/大屏上不拉满 |
| 圆角 | 16dp（`shapes.extraLarge`） | 容器档 |
| 内边距 | 22dp 横向 / 20dp 纵向 | |
| 底色 | `surfaceBright` | 浅色纯白、深色比页面亮一档，浮起感来自这里而不是叠阴影 |
| 图标容器 | 40dp 方块 + 10dp 圆角 + 21dp 图标 | 同心圆角：容器 10dp，图标内边距 10dp |
| 标题 | `titleLarge` 19sp SemiBold | |
| 正文 | `bodyMedium` 14sp / 21sp，`onSurfaceVariant` | |
| 按钮高 | 44dp | 触摸下限之上 |

**按钮分层**（规则 06）：

- 主操作 = `Button` 实心（primary 底 / onPrimary 字）
- 次操作 = `TextButton` + `onSurfaceVariant` 字
- 破坏性 = `Button` 实心 **error 底 / onError 字**

破坏性那一版先试过 `errorContainer` 浅底深字（符合规则 14 的"浅底深字"），渲染出来偏软——"彻底删除"和"取消"的视觉重量差得不够。最终改回 `error` 实心：这是整屏唯一的高饱和块，用户在这里停顿半秒是好事。图标容器仍保留 `errorContainer` 浅底，避免出现两块同样重的红。

**键盘**：`decorFitsSystemWindows = false` + `safeDrawingPadding()`，重命名弹窗在键盘弹出时整体上移，不再被遮。

**关闭**：`close()` 先播 120ms 退场再回调 `onConfirm`，并用 `closing` 标志防重入。代价是确认操作延迟 120ms，换来"点击有回应"。

## 4. 按钮与按压反馈

新增 `Modifier.pressFeedback(interactionSource, pressedScale)`：

```kotlin
// 按下 90ms 到位，松手 160ms 回弹；只动 transform，不碰布局
Modifier.pressFeedback(source, pressedScale = MotionSpec.PRESS_SCALE_ICON)
```

松手比按下慢是刻意的：下压要"立刻承认"，回弹要有"弹回来"的过程。

| 控件 | 缩放 | 依据 |
|---|---|---|
| 播放键 60dp | 0.94 | 圆面积小，4% 刚好 |
| 跳过键 48dp | 0.90 | 小物件，10% |
| 返回键 48dp | 0.90 | 同上 |
| 倍速键 | 0.94 | |
| 长条按钮（弹窗 / 重发） | 0.98 | 横向尺寸大，2% 已是上限 |

其余按钮改动：

- **播放/暂停图标**：`AnimatedContent` 交叉淡入 + `scaleIn/scaleOut`（0.80 → 1，150ms 进 / 110ms 出）。原版是 `if (playing) Pause else PlayArrow` 瞬切。
- **播放三角形光学居中**：`PlayArrow` 在 24dp 画布里几何居中但视觉偏左，`offset(x = 1.5.dp)` 补正（规则 12 / zxh 的 optical alignment）。
- **倍速文案**：`"${speed}x"` → `formatSpeed()`，输出 `1×` 而不是 `1.0x`。用真乘号 U+00D7，小写 `x` 在中文字体里会掉到基线以下。
- **倍速菜单**：当前项加 `Check` 图标 + primary 色文字。原来六项长得完全一样，选中的那个没有落点。
- **倍速数字切换**：`AnimatedContent` 130ms 交叉淡入。
- **跳过键图标** 24 → 26dp：原来相对 60dp 播放键偏小。
- **重发行**：`padding(horizontal = 14.dp)` 收敛，计数文案加 `weight(1f)` + 右对齐——原来 360dp 屏上会被顶出屏幕。

## 5. 界面切换

### 页面（`RecordNavHost`）

| | 之前 | 之后 |
|---|---|---|
| enter | fade 360 + slide `it/12` | 同，显式 `FastOutSlowInEasing` |
| exit | fade 240 | fade 240 + **40ms 延迟** |
| popEnter | 仅 fade 360 | fade 360 + slide **`-it/14`**（从左侧进入） |
| popExit | fade 240 + slide `it/12` | 同 + 40ms 延迟 |

两处判断：

1. **popEnter 补反向位移**。进入时从右侧滑入、返回时若只淡入，方向链就断了——用户不知道自己是"往回走"还是"又进了一层"。
2. **退出挂 40ms 延迟**。主角先动、配角后走；两个页面同时用满 360ms 会互相干扰，各让 40ms 反而更干净。

### 页内

| 场景 | 之前 | 之后 |
|---|---|---|
| 标记卡展开 | `animateContentSize()` 默认 spring（带回弹） | `tween(240, FastOutSlowInEasing)`，接近抽屉阻尼 |
| 展开箭头 | 180° 瞬翻 | `tween(220)` 旋转 |
| 进度条拖动 | 播放头无变化 | 播放头 ×1.35（进 110ms / 退 200ms） |
| 进度条光晕 | 半径 2.6× 轨道高、alpha 0.25 | 2.1×、0.18（原尺寸直径 41dp，比播放键还抢） |
| 迷你播放条 | 已用 slide + fade | 播放图标换成 `AnimatedContent` |
| 全屏看图 | 瞬间弹出 | 蒙版淡入 + 图片 0.93 → 1（240ms），关闭先收 120ms |

## 6. 动效参数

定义在 `ui/theme/Motion.kt` 的 `MotionSpec`，全应用只此一份。

| 常量 | 值 | 来源 |
|---|---|---|
| `PRESS_IN_MS` | 90 | 规则 25「按下时立即生效（约 80ms）」 |
| `PRESS_OUT_MS` | 160 | 回弹比下压软 |
| `DIALOG_ENTER_MS` | 200 | 下拉/浮层 180–250ms |
| `DIALOG_EXIT_MS` | 120 | 退出约为进入的 60% |
| `PAGE_ENTER_MS` | 360 | 整页切换 350–500ms，取区间下沿（320 是错的，已改回） |
| `PAGE_EXIT_MS` | 240 | 进入的 67% |
| `FOLLOW_MS` | 40 | 配角晚 40–80ms |
| `POP_IN_SCALE` | 0.95 | 「从 0.96 左右开始，不从 0」 |
| `POP_OUT_SCALE` | 0.97 | 退出比进入收得更少 |

系统「减少动态效果」：`rememberReducedMotion()` 读 `ANIMATOR_DURATION_SCALE`，在页面切换、按压反馈、弹窗与看图关闭的 `delay` 上都做了短路；其余 `animate*AsState` / `AnimatedContent` 由 Compose 的 `MotionDurationScale` 兜底，本身就会瞬间到位。
