## 2. 根因诊断

1. **动态取色抹掉了品牌识别**：`RecordTheme` 在 Android 12+ 走 `dynamicLight/DarkColorScheme`，App 配色跟随壁纸；同时 `BrandAccent()` 硬编码品牌绿。两套色系同时存在，是"配色很乱"的根因。已改为默认关闭动态取色（保留开关）。
2. **色板只填了 6 个 role**：`surface / surfaceVariant / outline / tertiary` 全是 M3 默认的淡紫系，卡片用 `surfaceVariant.copy(alpha=.45f)` 落在淡紫上，与绿色主色相冲。已补全全部 role（含 `surfaceContainer*`）。
3. **按钮没有金字塔**：设置页 10 个实心 Button，等于没有主操作。已按「每区一个主操作」重排。
4. **热区不足**：首页卡片右上角 ⋮ 只有 28dp，低于 40dp 最小热区，实际很难点中。已改 40dp。
5. **间距亲疏倒置**：卡片间距 5dp、内边距 14dp，卡片几乎粘连。已改卡间 8 / 内边距 16。
6. **文字截断**：`maxLines` 没有配 `overflow`，长标题被硬切。已补 `Ellipsis`。
7. **语义色缺失**：进度条暂停点写死 `#FF9800`，"待发送/发送中"共用 M3 tertiary（粉），与"失败红"混淆。已收敛到 `RecordColors`，并为状态条补圆点（颜色 + 形状双通道）。
8. **深色模式启动白闪**：窗口背景仍是主题默认白色，`windowLightStatusBar=true` 写死。已加 `values-night/themes.xml`。

## 5. 追加改动（同日，v1.3.0 一并发布）

### 5.1 首页按课程筛选

- `HomeViewModel` 拆成 `allSections`（全量）→ `courses`（出现过的课程名）→ `sections`（按选中课程过滤）。
- 筛选用录音命中的 `courseName`，不是用户改过的展示标题——改名后仍能按课程筛。
- 交互：`全部` + 各课程 FilterChip，带课程色点；再点已选中的课程 = 取消筛选；筛选后为空时给「查看全部」出口。

### 5.2 进度条对比度实测（WCAG 2.x 相对亮度计算）

| 组合 | 浅色 | 深色 | 阈值 |
|---|---|---|---|
| 角标文字 / 角标底 | 11.35:1 | 10.42:1 | 4.5 |
| 角标底 / 轨道 | 10.75:1 | 10.17:1 | 3.0 |
| 已播放 / 轨道 | 4.43:1 | 7.02:1 | 3.0 |
| 成功点 / 轨道 | 4.37:1 | 7.30:1 | 3.0 |
| 待发送点 / 轨道 | 4.93:1 | 6.95:1 | 3.0 |
| 失败点 / 轨道 | 5.43:1 | 7.44:1 | 3.0 |
| 暂停点 / 轨道 | **2.24:1 → 4.30:1** | 7.30:1 | 3.0 |

- 角标本身在深色模式（浅底深字）反而比浅色更宽裕，无需调整。
- 唯一不合格项是浅色模式的暂停菱形 `#E08A00`，改为 `#C2410C` 后 4.30:1。
- 顺带发现并修复：角标圆心原来在 2.8dp，被 52dp 画布顶边裁掉一半——画布加到 60dp、轨道下移 4dp。
