## 2. 根因诊断

1. **动态取色抹掉了品牌识别**：`RecordTheme` 在 Android 12+ 走 `dynamicLight/DarkColorScheme`，App 配色跟随壁纸；同时 `BrandAccent()` 硬编码品牌绿。两套色系同时存在，是"配色很乱"的根因。已改为默认关闭动态取色（保留开关）。
2. **色板只填了 6 个 role**：`surface / surfaceVariant / outline / tertiary` 全是 M3 默认的淡紫系，卡片用 `surfaceVariant.copy(alpha=.45f)` 落在淡紫上，与绿色主色相冲。已补全全部 role（含 `surfaceContainer*`）。
3. **按钮没有金字塔**：设置页 10 个实心 Button，等于没有主操作。已按「每区一个主操作」重排。
4. **热区不足**：首页卡片右上角 ⋮ 只有 28dp，低于 40dp 最小热区，实际很难点中。已改 40dp。
5. **间距亲疏倒置**：卡片间距 5dp、内边距 14dp，卡片几乎粘连。已改卡间 8 / 内边距 16。
6. **文字截断**：`maxLines` 没有配 `overflow`，长标题被硬切。已补 `Ellipsis`。
7. **语义色缺失**：进度条暂停点写死 `#FF9800`，"待发送/发送中"共用 M3 tertiary（粉），与"失败红"混淆。已收敛到 `RecordColors`，并为状态条补圆点（颜色 + 形状双通道）。
8. **深色模式启动白闪**：窗口背景仍是主题默认白色，`windowLightStatusBar=true` 写死。已加 `values-night/themes.xml`。

## 6. 第二轮：骨架重做（2026-10-21）

第一轮只换了 token（配色/圆角/间距），骨架仍是「顶部工具栏 + 白卡列表 + FAB」——任何 Material 模板都长这样，所以观感依然平庸。这一轮换骨架。

### 6.1 首页：卡片列表 → 时间轴

- 左列时间（16sp semibold、等宽数字）+ 时长（"98 分钟"，不再用 01:38:12 这种会被误读成时刻的写法）
- 中间一条贯穿分组的轴 + 课程色节点（首行/末行端点收在节点上，线不会戳出分组）
- 右侧课程名 + 讲解进度（"3 个标记 · 全部已讲解" / "5 个标记 · 2 个未讲解"，失败用 error 色 + 警示图标）
- 取消卡片容器：卡片会把每条录音切成互不相干的方块，时间轴才像"一学期的课堂记录"
- 分组头：日期 + 星期 + 细线 + 条数；行入场用 `animateItem()`
- FAB 改为实心主色：全页唯一的高饱和块，主操作才立得住

### 6.2 搜索与日期跳转

- 搜索行与日期按钮合成一行（都是"找某段录音"的入口）：`BasicTextField` + 日历按钮，高 42dp
- 搜索范围：标题 + 课程名 + 标记文字 + AI 回复前 500 字（`HomeItem.searchText`，小写化后 `contains`）
- 日期跳转：Material3 `DatePickerDialog` → 按 UTC 取回日期（否则东八区会差一天）→ 找到对应分组头在 LazyColumn 的索引 → `scrollToItem`；那天没录音就退到最近的一天并提示

### 6.3 回放页头部

- 顶栏从"只有一个标题"改为「课程名 + 日期 · 时长」，回调放回放时最常确认的三项

### 6.4 教训

- 只改 token 不叫改版：配色再统一，骨架平庸依然平庸
- 别画不存在的功能（中途一版 mock 里加了搜索图标，但当时并没有搜索功能）

## 7. 第三轮：主角屏与材质细节（2026-10-21）

第二轮解决了"骨架像模板"，但录音页还是功能原样：一个粗进度环 + 一行状态文字，且这一页**没有 Scaffold**，底部按钮直接压在手势导航条上。这一轮把录音页当主角屏重做。

### 7.1 录音页：进度环 → 声纹环

- 服务侧新增 `RecordingState.level`（`MediaRecorder.maxAmplitude / 32767`，随 500ms 心跳上报；暂停/打断时为 0）
- 环由 60 根条组成，**一根条 = 最近一分钟里的一秒**：已过的秒按那一秒的峰值取长度与透明度，未到的秒是浅灰短桩，当前秒实时长出来
- 一个元素同时表达进度与响度，替掉了"进度弧 + 秒刻度"两套同心刻度（试过，视觉上像圣诞树）
- 中心三层：计时（34sp 等宽）→ 脉动圆点 + 状态 → 已标记数量
- 补 `Scaffold`：底部按钮不再压手势条；顶部加返回（回首页，录音继续，与首页横幅一致），标题区给出"几点开始 · 已录多久"
- 打断原因从环中心移到底部独立一行（环中心只放得下四个字）

### 7.2 首页细节

- 回收站图标 `Delete` → `RestoreFromTrash`：垃圾桶图标读起来像"清空"，回收站要的是"还原"
- 大标题下加统计行："12 条录音 · 共 9 小时 24 分"；筛选课程时变成"高等数学 · 12 条录音 · 共 …"
- 空状态换成与应用图标同母题的五段声波（自绘 Canvas），文案指向右下角的 FAB

### 7.3 设置页

- 三个跳转行加图标块（课程表=主色/日历，AI=三级色/闪亮，数据=次级色/文件夹），色相区分 + 同色 12% 底
- 行内边距 14 → 12，加图标后行高不变

### 7.4 教训

- 同一屏上两套刻度（进度弧 + 秒刻度）会互相稀释，宁可让一个元素承担两件事
- 空状态插图用品牌母题（声波）比通用图标（音符/麦克风）更像"这个 App 的空状态"

## 8. 第四轮：动效与可用性细节（按 two skills 的规则自查）

用 `zxh-make-interfaces-feel-better` 的清单逐条过了一遍，改的是"规则能判定对错"的地方，不是凭感觉。

| 规则 | 之前 | 之后 |
|---|---|---|
| 热区 ≥40dp | 搜索清除 34dp、日期 38dp、卡片 ⋮ 36dp | 全部 40dp |
| 动效可中断 | 当前音量条每 500ms 硬跳一格 | `Animatable` 推进 260ms，目标变化时中途改向 |
| 进入/退出分离 | 状态文字硬切 | `AnimatedContent`：进入 200ms、退出 120ms |
| 颜色不硬切 | 圆点颜色随 if 直接换 | `animateColorAsState` 220ms |
| 图片描边 | 缩略图边缘在深色底上糊开 | 1dp `onSurface@10%` 描边收住轮廓 |
| 动态数字等宽 | 播放进度 `00:12 / 01:30` 会左右抖 | `tabularNumbers()` |
| 过渡作用域 | 页面切换无过渡 | `NavHost` 淡入 + 1/12 屏宽横移，退出更短 |

未做：按下缩放 0.96 —— Android 上 Material 的 ripple + elevation 已经是触觉反馈的既有语言，再叠缩放会显得"iOS 化"。
